# Static portfolio (HTML/CSS/JS)
1. Edit the CONFIG block at the top of script.js (name, projects, prices, email, links).
2. Put your photo at images/profile.jpg (portrait, about 800x1000).
3. For a working contact form: get a free key at web3forms.com and paste it as web3formsKey.
4. Test locally: open index.html in a browser.
5. Deploy: push this folder to GitHub, then Vercel > Add New Project > pick the repo > Deploy.
6. Contact form: works with no signup. The FIRST message sent from the live site makes FormSubmit email you an activation link: click it once. After that every message lands in your inbox. (Optional upgrade: a Web3Forms key in script.js.)
7. WhatsApp: put your number (country code, no + or spaces) in script.js as whatsapp.
